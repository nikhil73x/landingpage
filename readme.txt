On a new Windows device:

Install Node.js 20.9 or newer.
Extract Grand-Line-Ledger.zip.
Double-click start-local.bat. On first run, it downloads the project dependencies and starts the app.
Open http://localhost:3000/.

Open the project folder in Command Prompt / PowerShell and run:

npm install

instead of:

npm ci

Then:

npm run dev

and open:

http://localhost:3000
